# 🧠 Perceptrón — Red Neuronal Artificial

Implementación de un **Perceptrón simple** desarrollado en MATLAB como laboratorio de Inteligencia Artificial. Incluye entrenamiento y prueba con compuertas lógicas clásicas.

![MATLAB](https://img.shields.io/badge/MATLAB-App_Designer-0076A8?style=flat&logo=mathworks&logoColor=white)
![IA](https://img.shields.io/badge/Red_Neuronal-Perceptrón-6A5ACD?style=flat)

---

## 📌 Descripción

El Perceptrón es el modelo más básico de red neuronal artificial. Este proyecto implementa su algoritmo de entrenamiento y lo prueba con tres compuertas lógicas, ajustando los pesos automáticamente hasta converger en la solución correcta.

---

## ✨ Casos de prueba

| Archivo | Compuerta | Descripción |
|---|---|---|
| `Salidas_caso1_OR.txt` | OR | Salida 1 si alguna entrada es 1 |
| `Salidas_caso2_AND.txt` | AND | Salida 1 solo si ambas entradas son 1 |
| `Salidas_caso3_NAND.txt` | NAND | Inverso de AND |

---

## 🧠 ¿Cómo funciona?

1. Se cargan las entradas desde `Entradas.txt`
2. El perceptrón ajusta sus pesos iterativamente
3. Los pesos iniciales se guardan en `pesos.txt`
4. Los pesos finales entrenados se guardan en `pesos_finales.txt`
5. Las salidas de cada caso se guardan en la carpeta `Salidas/`
